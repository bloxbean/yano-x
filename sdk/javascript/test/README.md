# Topic client vectors

`vectors.json` is copied without modification from Yano
`core-api/src/test/resources/topics/v1/vectors.json` at commit
`7f92fbe6a150fa1320ac089a88f1a3334efd71e1`. Its independent generator is
`scripts/topics/generate_topic_vectors.py` (Python cbor2 + PyNaCl), and it is
also shipped as a Java SDK test resource under `sdk/client/src/test/resources/topics/v1/`.
These fixtures are never generated by the codec under test.

`ed25519-edge-vectors.json` records the 12 adversarial cases pinned by that
host's `StrictEd25519Test`, with the expected libsodium-compatible verdict.
Original corpus: `novifinancial/ed25519-speccheck`, commit
`65519336fda78a3d016e947df6d82848aca0c9da`, Apache-2.0.
The source identifier is retained in the fixture.

The fixed seed values used by tests are public fixture material only.
