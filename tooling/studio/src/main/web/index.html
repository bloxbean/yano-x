App-Chain Studio

Compose state machines
with bindings.

The binding editor writes the bindings document a chain runs when it combines several state machines. Studio never requests or stores private keys.

Set up an application

Applications are created and sealed with the CLI in the Yano X distribution, together with the other operators:

./yano.sh appchain try        # practise every step on one machine
./yano.sh appchain new        # create a draft; reference your bindings file with --chain id=bindings:file.yaml
